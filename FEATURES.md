# Features — BrandGuard AI Round 3

## Implemented and runnable
- Deterministic sample-rule review and human-readable findings.
- Suggested rewrite, copy/apply and text report export.
- TXT/Markdown upload, word/character count and draft recovery in current browser.
- Server-side saved review submissions and decisions.
- Review queue loaded from the server.
- Server-side activity log for assignments, role labels, comments and review decisions.
- Health endpoint and JSON REST API.

## Not implemented; do not claim as delivered
- LLM-based/context-aware AI analysis, approved-guideline retrieval, evidence/source verification.
- Authentication and secure role-based access control.
- Live CMS integration or publishing.
- Production-grade database, multi-instance synchronization, notifications or automated browser E2E tests.
